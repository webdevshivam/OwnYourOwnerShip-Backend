# OwnYourOwnerShip - Backend

Backend service for OwnYourOwnerShip built with ASP.NET Core Web API (.NET 9).

## Tech Stack
- **Framework:** ASP.NET Core Web API
- **Language:** C#
- **Documentation:** OpenAPI / Swagger

## Getting Started

### Prerequisites
- [.NET 9 SDK](https://dotnet.microsoft.com/download)

### Run the API
```bash
dotnet restore
dotnet build
dotnet run --project Tracker.App
```
